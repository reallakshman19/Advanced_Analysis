## Q1 — Production Trace
Trace the exact custody path from a current EMP.1 calculation to a deployment-binding decision:

```text
current governed execution
→ REVIEW_ACCEPTED engineering review
→ emp1-engineering-record-package/v1
→ emp1-engineering-record-release-qualification/v1
→ deployment authorization binding
```

Identify the exact hashes/identities carried at each boundary and explain why `deploymentAuthorized` must not be derived directly from the calculation, assessment PASS, review acceptance, package identity, or release-qualification record identity.

